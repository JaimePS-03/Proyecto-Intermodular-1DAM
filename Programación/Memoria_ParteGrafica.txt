Parte gráfica del proyecto
La interfaz gráfica del trabajo se ha realizado con Java Swing, utilizando componentes como JFrame, JPanel, JLabel, JButton, JTextField, JScrollPane, JTable y DefaultTableModel. Para la organización visual de las ventanas se ha usado setLayout(null) junto con setBounds(...), lo que ha permitido colocar cada elemento de forma manual y adaptada a cada pantalla.

En la estructura de las ventanas también se han empleado clases como EmptyBorder, BorderFactory, GridLayout y Font, además de colores personalizados creados con Color. Para mejorar la experiencia visual se han configurado propiedades como setBackground(...), setForeground(...), setFont(...), setCursor(...), setFocusPainted(false) y setBorderPainted(false) en los botones.

En las tablas se ha trabajado con JTable, JScrollPane, DefaultTableModel, JTableHeader y DefaultTableCellRenderer, permitiendo mostrar los datos de forma ordenada y con una cabecera personalizada. También se han utilizado ActionListener y expresiones lambda en los eventos de los botones para abrir ventanas, insertar registros, actualizar datos, eliminar elementos y limpiar campos.

A nivel de navegación, la aplicación se ha organizado en varias ventanas como VentanaPrincipal, VentanaPrincipalJefe, VentanaGJefes, VentanaBartender, VentanaCamareros y VentanaCocineros, todas creadas como clases que heredan de JFrame. Esto ha permitido separar las distintas funcionalidades del programa en interfaces independientes pero conectadas entre sí.

En conjunto, el proyecto utiliza principalmente clases estándar de Java como JFrame, JPanel, JButton, JTextField, JTable, DefaultTableModel, Color, Font y ActionListener, consiguiendo una aplicación de escritorio estructurada y coherente.
